Run your rule corpus against known positive and negative samples as well as your Go tests. Review [compatibility differences](/go-yara/compatibility/) if you depend on native module behavior or move rules between engines.

## Compiled rule caches

<p>New serialized programs use format {release.format}. This release reads formats {release.readableFormats.join(', ')}. A binary whose reader does not support format {release.format} cannot load new artifacts. Rebuild caches from rule source when the consuming binary cannot read their format.</p>

Keep the library version with a stored cache and retain the original rule source. When rolling out multiple versions of a service, avoid overwriting a shared cache with an artifact that older instances cannot read.

Pass compatible custom module handlers to `UnmarshalCompiledProgram(blob, modules...)` when loading; missing or incompatible function signatures cause a load error. Bind external values and host data on the restored scanner. The [custom-module example](/go-yara/modules/#custom-functions-and-caching) exercises this sequence, including the missing-handler failure.

Structured schemas are preserved, but callbacks, external values, scanner options, host data, and previous scan results are not an application-state snapshot. Keep the original rule source and runtime configuration alongside your cache policy. A compiled artifact is specific to go-yara; it is not a libyara compiled-rule file.

## Documentation versions

The site rebuilds when a release is published or `main` changes. Version details, module signatures, the serialized format number, and CLI help come from the latest stable release. The displayed Go and CLI examples run against that release and the current source tree before deployment.

Behavioral explanations still need review when code changes. Deployment waits for a recorded prose review of each release. The repository's [documentation maintenance guide](https://github.com/cawalch/go-yara/blob/main/site/README.md) maps code changes to pages, and its [writing guide](https://github.com/cawalch/go-yara/blob/main/site/WRITING.md) records the editorial standard.
