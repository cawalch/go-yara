## Browser playground

<Playground />

The playground returns rule names and string offsets; it does not enable evidence extraction or validate credentials. The [credential evidence examples](/go-yara/scanning/#credential-evidence-and-validation) show capture fields, correlation status, and validator handoff in Go.

## Create a Go module

With Go installed, create an empty directory and add go-yara:

<Code code={`mkdir yara-example
cd yara-example
go mod init example.com/yara-example
go get github.com/cawalch/go-yara/compiler@${release.version}`} lang="sh" />

See [installation](/go-yara/installation/) for the required Go version and CLI downloads.

## Compile and scan

Save this as `main.go`:

<Code code={example} lang="go" title="main.go" />

Run it:

```sh
go run .
```

The output is:

```text
greeting
```

The rule matches because the input contains `Hello`. Changing the input to `Goodbye` produces no output. Compilation and scanning return separate errors; handle both in application code.

## Reuse the program

Keep the compiled program when scanning more than one input. Its convenience methods manage pooled scanners, and the program supports concurrent scans. For custom options or repeated scans in one worker, [create a reusable scanner](/go-yara/scanning/#reuse-a-scanner).
