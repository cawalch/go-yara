`go-yara` compiles YARA rules and scans byte slices, readers, and files in Go. It runs without CGO or an installed copy of libyara, so you can include the engine in a Go service or build a standalone scanner.

[Quickstart](/go-yara/quickstart/) · [Browser playground](/go-yara/quickstart/#browser-playground) · [Installation](/go-yara/installation/)

## Library

Compile a rule set once and reuse the program across scans. Host modules expose application data to rules alongside the input bytes.

The engine supports text strings, hex patterns, regular expressions, and the built-in `hash`, `math`, `string`, and `time` modules. It also provides structured host modules and optional evidence extraction.

<span id="check-your-rules-before-migrating"></span>

## Compatibility

Native `pe` and `elf` parsers are not bundled, and go-yara has extensions that libyara does not accept. The [compatibility guide](/go-yara/compatibility/) identifies those boundaries. Test your rule corpus and expected matches before replacing another engine.

`ScanReader` buffers the entire input, and block scanning retains supplied blocks. See [input APIs](/go-yara/scanning/#input-apis) for memory use and condition evaluation.
